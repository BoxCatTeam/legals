## 引言

猫猫日历（NekoReki）是一款本地优先、离线可用的万年历与日程助手。我们坚持「数据归属于你」的原则：你的日程、纪念日、提醒与偏好仅保存在你自己的设备上，本应用不依赖任何服务器，也不要求你注册或登录。

本应用为开源软件（采用 MIT 或 Apache-2.0 双重许可），源代码公开发布于 GitHub。这意味着本政策的每一条声明都可被源代码验证。

## 1. 我们收集的信息

**我们不收集任何个人信息。** 具体包括：

- 不收集账号、手机号、邮箱等身份信息（本应用无账号体系、无登录功能）。
- 不收集设备标识（如 IDFA、Android ID、IMEI、MAC 地址）。
- 不收集位置信息，不申请定位权限。
- 不读取通讯录、相册、相机、麦克风。
- 不读取系统日历（你的日程仅保存在应用内部，不会与系统日历同步）。
- 不收集使用行为数据（无埋点、无统计、无崩溃上报）。

你主动创建的日程、纪念日、提醒事项及偏好设置（主题、农历显示选项等），属于**你的数据**，由你全权控制，仅在本地处理。

## 2. 信息的使用

你的数据仅在本地用于：

- 显示日历、农历、节气、宜忌等信息（全部在设备本地计算，无需联网）。
- 按你设置的提醒时间发送**本地通知**（通知内容不离开设备，也不上传到任何服务器）。

## 3. 信息的存储与安全

- 所有数据（日程、纪念日、提醒、偏好设置）均存储在设备本地的应用沙盒内（MMKV 本地存储），受操作系统沙盒与权限机制保护，其他应用无法访问。
- 本应用**没有服务器**，你的数据不会离开你的设备。
- Android 端已关闭系统云备份（`allowBackup=false`），应用数据不参与系统自动备份。
- iOS 端：应用本身不向任何云端上传数据；设备可能随操作系统级备份（iCloud 或电脑备份）包含应用数据，这是操作系统行为，与本应用无关。
- 数据不会被加密存储，请勿在应用中记录敏感信息（如密码、证件号、银行信息）。

## 4. 数据的保留与删除

- 你的数据将一直保留在设备上，直到你主动删除或卸载应用。
- 我们不主动保留、归档或备份你的数据；由于数据仅存于本地，卸载应用将永久删除本应用存储的全部数据。
- 删除权限完全在你手中--我们无法访问、导出或代你删除。

## 5. 信息的共享与传输

- **不共享**：我们不会向任何第三方提供你的数据。
- **不传输**：当前版本的业务功能不发起任何网络请求，不向任何服务器上传或下载数据。
- **无第三方数据 SDK**：本应用未集成任何广告、统计分析、崩溃上报或推送服务的第三方 SDK。

## 6. 权限说明

| 权限 | 用途 | 说明 |
|---|---|---|
| 通知权限（Android 13+ / iOS） | 发送日程与纪念日提醒 | 仅在你要提醒时按系统提示申请，可随时在系统设置中关闭 |
| INTERNET（Android） | React Native 框架默认声明 | 正式版业务功能不使用网络，不传输任何数据 |

## 7. 开源与第三方组件

本应用为开源软件（MIT 或 Apache-2.0），源代码可在 GitHub 公开查看与审计：<https://github.com/BoxCatTeam/nekoreki>。

本应用基于开源组件构建（React Native、react-native-paper 等）。这些组件仅在设备本地运行，不会收集或传输你的数据。各组件许可信息可在应用内「关于」页面查看。

## 8. 儿童隐私

本应用不收集任何个人信息，因此不存在儿童个人信息处理问题。若未来政策发生变化，我们将另行说明。

## 9. 你的权利与控制

- **查看与删除**：你可以在应用内随时查看、编辑或删除自己创建的日程、纪念日与提醒。
- **清除数据**：清除本应用的存储数据（或在系统设置中「清除数据」），即可删除全部本地数据。
- **卸载即删除**：卸载应用将删除本应用存储的全部数据。
- **关闭通知**：可在系统设置中随时关闭本应用的通知权限。

## 10. 政策变更

如本政策发生变更，我们将在应用内（「关于」页面）或本文件所在页面公布更新，并标注新的生效日期。重大变更（如引入服务器、开始收集数据）将以显著方式提前告知。
