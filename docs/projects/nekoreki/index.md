# 猫猫日历（NekoReki）

> 一款本地优先、离线可用的万年历与日程助手，支持农历、节气、纪念日提醒。

## 项目简介

猫猫日历（NekoReki）是 BoxCat Team 的一款 React Native 跨平台万年历应用，iOS 采用 Liquid Glass、Android 采用 Material Design 3。数据全部本地化存储，无账号体系，不依赖任何服务器。

- 项目主页：<https://github.com/BoxCatTeam/nekoreki>
